# A customer contact manager for my business

Auto-generated full-stack application.

## Structure
- `index.html` - Frontend (PWA, responsive)
- `backend/` - FastAPI backend (SQLite + SQLAlchemy)
- `admin.html` - Admin panel

## Run locally
Then open: http://127.0.0.1:8000

## Deploy to Render (free)
1. Push to GitHub
2. Connect repo on render.com
3. Uses `render.yaml` automatically

## API
- Health: `GET /api/health`
- Docs: `GET /docs`
- Admin: `GET /admin`
